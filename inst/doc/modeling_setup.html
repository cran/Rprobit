Modeling Setup

In this vignette we present the modeling workflow for three examples, two being real world data sets and the third using a simulated data set. The core function described is the setup function.

The setup() Function

For the estimation of a multinomial probit model (MNP model) we need to

  • structure the data set, often contained in a data.frame. Details on this structuring can be found in the vignette Data and Simulation.
  • define the model to be estimated. Details on the modeling can be found in the vignette Model Definition.
  • run the numerical estimation procedure. Details on this step can be found in the vignette Model Fitting.

The setup function combines the first two of these steps to provide an object of the Rprobit class. We use an R6 class for these objects. For details on the perils of R6 classes see this website.

The input arguments for the setup() function depend on the use case. This will be described for three use cases in the following.

Setup Example for Empirical Choice Data in Wide Format

In the choice data vignette Data and Simulation we discuss setting up the data structure for the Train data set in mlogit (Croissant 2020). For setting up the model including the data set we have to do little more than to set up the choice data structure:

data("Train", package = "mlogit")

train_model <- setup(
  formula = choice ~ price + time + change | 0 | comfort,
  df = Train,
  column_decider_id = "id",
  column_occasion_id = "choiceid"
)
train_model$mod$H_b <- train_model$mod$H_b[, -1]
train_model$mod$f_b[1] <- -1
train_model$mod$H_L <- matrix(c(0, 0, 1), ncol = 1)
train_model$mod$f_L <- c(0, 0, 0)

print(train_model)

Additionally the object contains information initialized to NULL that will be filled during the estimation:

  • ll_fit value of the criterion function after fitting
  • hessian_fit estimate of Hessian matrix of criterion function after fitting
  • Vhat_fit estimate of variance of the score vector after fitting
  • theta_fit estimated parameter vector
  • theta_init initial parameter vector
  • theta_vcov estimate of the variance matrix

This will be filled after estimation is done. For estimation we need to define an initial estimate and subsequently run the numerical search. Details on this can be found in the vignette Model Fitting. Here we only present the workflow for the case study:

train_model$fit(print.level = 0, cml_type = "probit")
#> Looking for initial values...
#> Starting numerical optimization...
#> Calculating approximated Hessian at estimate...
#> Done.

Setup Example for Empirical Choice Data in Long Format

Setup Example for Simulated Choice Data

If no empirical data are supplied, setup() can be used to simulate choice data. In this case, the input argument alt_names defines the number and names of alternatives. The simulation uses centered normal regressor values with a standard deviation set by sd. When no parameter vector is specified it is obtained from independent standard normal draws.

set.seed(1)
sim_model <- setup(
  formula = choice ~ quality + price | income | time,
  re = "quality",
  alt_names = c("bus", "car", "train"),
  ref_alt = "bus",
  corr_re = FALSE,
  error_struc = "diag",
  N = 300,
  Tp = rep(3, 300),
  sd = 2
)

print(sim_model)
